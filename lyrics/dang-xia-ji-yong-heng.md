# 当下即永恒

湖水把天空托在手心
我坐下 不数时辰
风从耳边过去
没带走什么 也没留下

不回头看 不向前望
潮水把过去和未来一起退走
此刻像一颗透明的石头
沉在胸口 不重 不轻

我听见自己的呼吸
我听见自己的心跳
原来我活着——
不需要别的证据

当下 即永恒
当下 即永恒
时间在我身上停下来
没留下一道流过的痕

我属于我自己
完整 安静
灵魂里没有一寸空
不必由谁来填

不在权势里
不在财富里
不在任何一双看着我的眼睛里
我的福祉 是这一口水
喝下去 就够了

我是我自己的观察者
也是我自己唯一的裁判
没有人替我活
所以也没有人替我评判

我听见自己的呼吸
我听见自己的心跳
原来我活着——
不需要别的证据

当下 即永恒
当下 即永恒
时间在我身上停下来
没留下一道流过的痕

我属于我自己
完整 安静
灵魂里没有一寸空
不必由谁来填

后来有人告诉我
这个湖叫圣彼得岛
有一个叫卢梭的人
也曾在这里坐过一下午

他说他那一刻
完全感觉不到时间
他说那一刻
他完全是他自己

可是这一刻太满了
满到 我忽然想——
真希望有人也看见这片湖
真希望有人 知道我此刻坐在这里

就是这一念
时间 重新找到了我
那条通向远方的路
也重新找到了我

湖水还在
天空还在
永恒——
从我胸口悄悄退潮

而我 抬起头
第一次 把目光 投向了远方的人
